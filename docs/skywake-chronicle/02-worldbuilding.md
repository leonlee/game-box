# 02. 世界观与叙事框架

## 1. 世界设定（原创）

世界由浮空群岛组成，岛与岛之间是“云海航路”。

- 上层：日照海（文明密集区）
- 中层：风暴带（主航路风险区）
- 下层：黯潮域（禁区）

每座岛由“天核”维持悬浮。天核衰竭会导致坠岛灾难。

## 2. 核心冲突

- 古代文明“织星者”遗留的“律印”被重新发现。
- 律印可影响自然法则，引发权力争夺。
- 主角团在救援任务中卷入多阵营战争与古代真相。
- 冲突双主轴并行：
  - 资源轴：航路、能源、遗迹控制权争夺
  - 理念轴：秩序净化、自由自治、技术中立之间的价值冲突

## 3. 阵营

1. 赫利欧商联
   - 目标：控制贸易与航路
   - 风格：契约、资源、雇佣
2. 圣白誓庭
   - 目标：净化黯潮、统一秩序
   - 风格：神权、军团、审判
3. 黑羽自治圈
   - 目标：保护边境岛民自治
   - 风格：游击、情报、民兵
4. 第七码机工城
   - 目标：解析遗迹技术
   - 风格：技术中立、实验至上

## 4. 角色来源

- 玩家队伍由“远航委托局”注册。
- 三名角色可来自不同出身，形成冲突与互补。
- 角色通过“高概念/麻烦/背景标签”驱动个性与事件分支。

## 5. 主线章节骨架（12章）

1-3章：边境危机与组队  
4-7章：阵营冲突升级  
8-10章：下潜黯潮，揭开古代事实  
11-12章：终局抉择（封印 / 共存 / 重构秩序）

## 6. 日志表达规范

- 禁止“玄学空话”，必须有可行动线索。
- 事件文本分两层：
  - 叙事层：冒险报告口吻
  - 机制层：明确结果与原因标签（用于调参）

## 7. 叙事与命名风格拍板（2026-02-25）

1. 主线调性采用混合优先级：`热血王道 > 灾厄悬疑 > 阴谋政治`（A > C > B）。
2. 阵营冲突采用双主轴：资源争夺与理念冲突并行推进。
3. 名词风格采用“神秘遗迹派”：
   - 优先使用遗迹学、古语、律印体系术语。
   - 航海与阵营术语作为辅助，不主导名词系统。
