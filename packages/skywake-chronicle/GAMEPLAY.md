# Skywake Chronicle Prototype

该原型实现了文档中的核心闭环：

1. 城镇准备（队伍/战术/商店）
2. 选择迷宫与目标层
3. 自动探索并记录结构化日志
4. 回城结算（重惩罚）并继续调参

## 玩法入口

- `出征`：选择迷宫与目标层，查看 ETA，开始自动探索
- `队伍`：模板调参与手动规则编辑（JSON）
- `城镇`：任务与补给采购
- `仓库`：库存与最近 30 次出征记录
- `设置`：日志默认视图、引导显示、通知策略、存档导入导出

## 日志

- 支持 `叙事视图` 与 `调试视图`
- 支持按 `event_type` / `reason_tag` 过滤
- reason tags 对齐 MVP 规范（核心 + 扩展）
- 出征页提供“近期统计看板”（完成/撤退/失败率、平均推进、TOP 原因、建议模板）
- 支持“关键回合简化回放”（开战、阻断、撤退、结算）并可一键定位日志
- 日志条目默认两行摘要，支持点击展开；叙事视图按章节分段减少刷屏
- 日志支持“长按/右键快捷面板”：可直接按类型/原因筛选、定位回放、展开详情
- 日志支持“左右滑动捷径”：左滑按事件类型筛选，右滑自动定位最近回放步骤
- 出征页信息卡支持折叠/展开，减少长列表滚动负担
- 出征页新增吸顶关键操作区，移动端可快速执行派遣/暂停/结算/日志跳转

## 规则编辑

支持两种规则编辑路径：

- 触控规则卡片编辑器（启用/停用、优先级加减、模板新增、删除）
- 触控条件编辑抽屉（支持多叶子选择、`all/any` 切换、叶子增删、`fact / op / value` 编辑）
- 手动编辑战术规则 JSON（完整高级编辑）

JSON 应用时会执行校验：

- 条件叶子上限 12
- 动作枚举上限 14
- scope 与 action 匹配
- 规则 ID 唯一且命名合法

## 引导与复盘增强

- 出征页支持“新手引导清单”，完成关键步骤后自动隐藏。
- 失败后支持“复盘建议”动作按钮（套模板、补给、重铸）。
- 连续失败任务支持一次性保护建议，降低卡关劝退。

## 存档与通知

- 支持浏览器通知（可配置全部结果通知 / 仅失败通知）。
- 支持导出当前存档 JSON 备份。
- 支持粘贴 JSON 导入并执行版本校验与迁移后覆盖。
- 调试视图支持“高级调试开关”，可选择是否显示 `rule_id`。
- 仅保留最近 30 次完整日志；更早 run 自动归档为汇总统计（成功率/原因分布/平均产出）。
