# Skywake Chronicle Prototype

该原型实现了文档中的核心闭环：

1. 城镇准备（队伍/战术/商店）
2. 选择迷宫与目标层
3. 自动探索并记录结构化日志
4. 回城结算（重惩罚）并继续调参

## 玩法入口

- `出征`：选择迷宫与目标层，查看 ETA，开始自动探索
- `队伍`：模板调参与手动规则编辑（JSON）
- `城镇`：任务与补给采购
- `仓库`：库存与最近 30 次出征记录

## 日志

- 支持 `叙事视图` 与 `调试视图`
- 支持按 `event_type` / `reason_tag` 过滤
- reason tags 对齐 MVP 规范（核心 + 扩展）

## 规则编辑

手动编辑战术规则 JSON 后点击“应用规则”会执行校验：

- 条件叶子上限 12
- 动作枚举上限 14
- scope 与 action 匹配
- 规则 ID 唯一且命名合法
